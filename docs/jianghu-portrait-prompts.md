# 江湖风云录 · 人物立绘提示词

用于战斗舞台的双方立绘与头像。共 **15 张**。

## 统一要求

- 构图：**胸像半身**，正面或四分之三侧脸，肩部以上占画面 70%
- 风格：中国水墨武侠、写实古风、电影感打光
- 背景：**深墨色/暗色纯底**（战斗舞台会给立绘叠暗角，纯色底最稳）
- 尺寸：**1:1 方形**，建议 1024×1024（游戏内最大显示 176×256，够用）
- 禁止：文字、水印、边框、多人、现代服饰、明显卡通化
- 保存：先存 PNG 也可以，我帮你转 webp

风格前缀（每条提示词前都加）：

```
中国水墨武侠风格人物半身像立绘，写实古风，电影感侧逆光，深墨色背景，胸像及肩，正面微四分之三侧脸，无文字无水印，方形构图：
```

## 放哪里

```
public/game/portraits/<文件名>
```

代码里 `PORTRAITS` 映射按**中文名 → 文件名**索引，文件名必须与上表完全一致（全小写，`.webp`）。

## 出完图之后

把文件丢进上面的目录，然后告诉我一声：

- 如果你直接存成 `.webp`，**不用做任何事**，刷新页面即生效
- 如果是 PNG/JPG，我跑一条命令批量转成 768×768 的 webp 覆盖进去
