## B 路线：火山方舟（即梦同源 Seedream）

1. 打开 [火山方舟控制台](https://console.volcengine.com/ark) → 开通「即梦·图片生成」→ 创建 API Key
2. 在项目根目录执行：

```powershell
node scripts/gen-scenes-ai.mjs --provider ark --key <你的ARK_API_KEY>
```

可选参数：

```powershell
--model doubao-seedream-3-0-t2i-250415   # 默认
--size 1280x720                          # 方舟固定档位
--only huashan,inn                       # 只跑指定场景
```

脚本会自动：出图 → 裁成 1600×900 → 压成 webp → 写入 `public/game/scenes/`。

## 已有兜底

目录里现在有 **22 张 Blender 3D 渲染的 webp**（低模实景风格），以及 **22 张 SVG**。代码取图顺序：

```
<key>.webp（优先） → 失败回落 <key>.svg
```

所以即梦的图一旦放进同名文件，页面立即换用，不用改代码、不用重新构建之外的额外操作。
