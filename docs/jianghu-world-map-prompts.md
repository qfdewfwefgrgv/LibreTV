# 江湖世界地图 · 美术提示词（修正版）

## 上一版为什么废了

我写的是「45 度斜俯视 **全景**」，模型理解成「城市鸟瞰插画」，于是给了：

- ❌ 透视投影（近大远小）→ 碰撞框没法对齐
- ❌ 整座城塞进画面（上千间屋）→ 角色只有 40px，站在城里像蚂蚁
- ❌ 带天空、远山、景深 → 不是可玩地图，是封面图

**一张能当游戏底图的地图，必须满足：无透视、无天空、尺度可玩、阴影方向一致。**

---

## 方案 A：单张正交俯视地图（1 张，最快见效）

只要一张，覆盖**洛阳城的一条主街**，不是全城。

**提示词（直接复制）：**

```
游戏关卡地图底图，中国古风武侠，正交俯视视角（正上方垂直向下看，无透视、无地平线、无天空、无远景），
画面是古代城镇的一条东西向主街：街宽约占画面八分之一，两侧并列木质店铺与青瓦屋顶，
屋檐投下统一的短阴影（光源在左上），街面铺青石板，街边有灯笼杆、布幌、水缸、木车，
色调青灰为主、局部暖黄灯火，平涂上色、边缘清晰、无景深模糊，
无人物、无文字、无UI、无边框，16:9 横向
```

**尺寸**：2048×1152 或 1536×864
**文件名**：`public/game/world/luoyang-street.webp`

**验收标准**（拿到图先看这四条，不满足就不用发我）：

1. 从上往下垂直看，**没有任何地平线或天空**
2. 照片里**没有远近差别**（近处的屋檐和远处的屋檐一样大）
3. 街道宽度**能并排站下两个角色**（角色约 64px 高时）
4. 没有人物、没有文字

---

## 方案 B：贴片集（推荐，效果最好、可无限拼）

单独出 12 个小素材，我来拼地图。这样街道宽窄、店铺间距、碰撞范围全在我控制内，能跟你走位完全对齐。

统一要求：**透明底 PNG/WebP、正俯视、光源左上、同一套色调**

| 文件名 | 尺寸 | 内容 |
|---|---|---|
| `tile-ground.webp` | 512×512 | 青石板地面，四方连续可平铺 |
| `tile-road.webp` | 512×512 | 主街石板路（带车辙纹），可平铺 |
| `obj-house-a.webp` | 512×512 | 俯视青瓦屋顶民居（单间，含屋檐投影） |
| `obj-house-b.webp` | 512×512 | 俯视两层楼阁屋顶（带重檐） |
| `obj-shop.webp` | 512×512 | 俯视店铺屋顶 + 门口布幌 |
| `obj-inn.webp` | 512×512 | 俯视客栈（更大，带院子） |
| `obj-temple.webp` | 512×512 | 俯视衙署大殿屋顶（朱红梁柱） |
| `obj-wall.webp` | 512×256 | 俯视城墙段（含垛口） |
| `obj-gate.webp` | 512×512 | 俯视城门楼 |
| `obj-tree.webp` | 256×256 | 俯视树冠（水墨枝叶） |
| `obj-lantern.webp` | 128×128 | 俯视灯笼杆 + 光晕 |
| `obj-bridge.webp` | 512×256 | 俯视石拱桥 |

**贴片提示词模板：**

```
游戏地图素材，中国古风武侠，正交俯视（正上方垂直向下看，无透视无侧面），
透明背景，单个物件居中、占满画面、边缘干净、光源左上方向投影，
平涂上色、色调青灰与暖黄、无文字无水印：
（例）青色筒瓦屋顶的单间民居，屋脊朝南北，可见四坡瓦面与檐口投影
```

**文件名**：`public/game/world/tiles/<上表文件名>`

## 两个方案的取舍

| | 方案 A | 方案 B |
|---|---|---|
| 出图量 | 1 张 | 12 张 |
| 上线速度 | 快 | 中 |
| 街道布局 | 我只能照图硬对碰撞 | **我随便拼，完全对齐** |
| 加新城市 | 重出一张整图 | 换配色复用同一批贴片 |
| 后期加建筑 | 得重画整图 | 多出一张贴片即可 |

我建议 **B**，一次到位；如果你只想先看效果，那就先出 **A** 的一张。
